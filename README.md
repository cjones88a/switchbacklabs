# Switchback Labs

Portfolio site. Training Coach reads Strava and asks Anthropic for a training week. The race page is fictional sample data.

## Quick Start

1. Copy environment values into `.env.local` for local Strava sign-in (`STRAVA_CLIENT_ID`, `STRAVA_CLIENT_SECRET`, `STRAVA_REDIRECT_URI`, `TRAINING_SESSION_SECRET`).
2. Run `npm run dev` and open http://localhost:3000.
